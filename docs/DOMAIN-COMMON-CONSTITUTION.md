# 공통 도메인 원칙

## 1. 도메인 정의

ReadMap의 핵심 도메인은 다음과 같다:

- **Member**: 사용자 인증 및 프로필
- **Book**: 책 정보 및 서재 관리
- **Map**: 세계지도 시각화 및 국가별 책 연결

## 2. 도메인 간 의존성

```
Map ← Book ← Member
```

- Map은 Book 데이터를 시각화한다
- Book은 Member(사용자)에 종속된다
- 상위 도메인은 하위 도메인을 직접 참조하지 않는다

## 3. 도메인 문서 원칙

- 새로운 도메인 추가 시 반드시 `DOMAIN-XXX-CONSTITUTION.md`와 `DOMAIN-XXX-STATUTE.md`를 생성한다
- 도메인 문서 없이 해당 도메인 기능을 구현하지 않는다
- 도메인 경계를 넘는 로직은 상위 도메인 또는 공통 서비스에 위치시킨다
