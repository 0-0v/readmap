# 회원 도메인 원칙

## 목적

회원 도메인은 사용자 인증(Authentication)과 프로필(Profile)을 관리한다.

## 원칙

- 인증 제공자는 Supabase Auth를 사용한다
- 이메일/비밀번호 및 카카오 소셜 로그인을 지원한다
- 인증 상태는 Supabase 세션으로 관리하며, 앱 전역에서 `authStore`를 통해 구독한다
- 비인증 사용자가 보호된 페이지에 접근하면 `/login`으로 리다이렉트한다
- 인증된 사용자가 게스트 전용 페이지에 접근하면 `/`로 리다이렉트한다
- 사용자 프로필(아바타, 지도 색상 등)은 `profiles` 테이블에서 관리한다
