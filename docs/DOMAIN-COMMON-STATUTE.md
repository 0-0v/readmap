# 공통 도메인 규칙

## 공통 타입 위치

- 여러 도메인에서 공유하는 타입은 `src/types/`에 정의한다
- 특정 도메인에서만 사용하는 타입은 해당 서비스 파일 내에 정의한다

## 공통 유틸리티

- 도메인 무관 순수 함수는 `src/utils/`에 위치한다
- 국가 데이터 관련 유틸: `src/utils/countries.ts`

## Supabase 클라이언트

- `src/lib/supabase.ts`의 단일 인스턴스를 사용한다
- 모든 서비스 파일은 이 인스턴스를 import해서 사용한다

## 에러 처리

- 서비스 함수에서 발생한 에러는 호출한 View로 throw한다
- View에서 사용자에게 토스트 또는 인라인 메시지로 표시한다
- 전역 에러 핸들러는 사용하지 않는다

## 상수

- 도메인 공통 상수는 `src/constants/`에 정의한다
